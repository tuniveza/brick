# brick's dictionary: everyday words, each taken to the nearest thing brick already understands.
#
# One word or phrase per line:   word = what it means here
# Lines starting with # are headings (the first line of a group) and notes. You can add, change or
# remove lines; brick reads this file each time it builds a program.
#
# A word only counts where its meaning fits, so "write I scribbled a crimson note" still shows those words:
#   words that mean an action (write, ask, wait ...) count as the first word of an action: scribble hello
#   colours count where a colour goes: write hi in crimson, set the colour to navy, turn teal
#   check words count after the thing being checked: if score exceeds 10
#   places count where a place on the screen goes: write hi at the top-left
#   value words count inside a value: write the greatest of a and b
# Gaps: "something", "something else" and "a number" stand for any words; "a colour" stands for a colour.
# A meaning of a few words with no gap is a whole action: "skip a line" works on its own, but
# "add a blank line to notes.txt" still adds those words to the file.
# The words you teach brick (to greet someone means ...) and the names in your program always come first.
